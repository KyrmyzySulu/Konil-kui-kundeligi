🌸 **КӨҢІЛ КҮЙ КҮНДЕЛІГІ**

Күнделікті эмоцияларды бақылауға арналған веб-жоба

⸻

📌 **Жоба туралы**

Көңіл күй күнделігі — пайдаланушылардың күнделікті эмоционалдық жағдайын жазуға, сақтауға және бақылауға арналған веб-платформа.

Жобаның басты мақсаты — адамның көңіл күйін күн сайын белгілеп, эмоционалдық өзгерістерін бақылауға мүмкіндік беру.

**Негізгі мүмкіндіктер**

* Күнделікті көңіл күйді белгілеу
* Күнделікке жеке жазбалар қосу
* Бұрынғы жазбаларды қарау
* Көңіл күй өзгерістерін бақылау
* Жазбаларды сақтау
* Көңіл күй тарихын талдау

**Қолданылған технологиялар**

* HTML — веб-беттің құрылымы
* CSS — дизайн және безендіру
* JavaScript — интерактивті функциялар

**Жобаның мақсаты**

Пайдаланушыларға өздерінің күнделікті көңіл күйін бақылауға, эмоционалдық жағдайын түсінуге және жеке жазбаларын сақтауға көмектесу.

Көңіл күй күнделігі — веб-жоба

Жоба туралы

Көңіл күй күнделігі — пайдаланушылардың күнделікті көңіл күйін жазып, бақылауға арналған веб-платформа.

Жобаның негізгі мақсаты — адамның эмоционалдық жағдайын бақылауға және көңіл күй өзгерістерін талдауға көмектесу.

Негізгі мүмкіндіктер

* Күнделікті көңіл күйді белгілеу
* Күнделікке жазба қосу
* Бұрынғы жазбаларды қарау
* Көңіл күй тарихын бақылау
* Көңіл күй өзгерістерін талдау
* Жеке жазбаларды сақтау

Қолданылған технологиялар

* HTML
* CSS
* JavaScript
